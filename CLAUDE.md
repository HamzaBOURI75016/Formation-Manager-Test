# Landing Page — Formation « Comment recruter dans un secteur pénurique »

## Contexte

Ce projet est une landing page d'inscription à une formation d'une journée sur les meilleures techniques pour recruter dans le social. Organisée par ESSentiel Talents.

## Informations de l'événement

- Nom : « Formation ESSentiel Talents — Comment recruter dans un secteur pénurique »
- Date : samedi 16 mai 2026
- Horaires : 10h00 - 18h00
- Format : 100 % en ligne (Google Meet)
- Tarif : 490 € HT (588 € TTC)
- Places limitées : 100 participants
- Public : professionnels tous secteurs, débutants
- Formateur : HMZ BRI

## Règles techniques

- Un seul fichier HTML auto-suffisant
- Tailwind CSS via CDN
- JavaScript inline
- Responsive mobile-first
- Pas de framework (pas de React, pas de Vue)
- Les données du formulaire sont stockées en localStorage (pas de backend pour le prototype)

## Règles de design

- Palette ESSentiel Talents :
  - Rouge bordeaux `#8B1E24` — couleur principale (titres, structure)
  - Orange `#EE7B24` — couleur d'accent (boutons d'action, éléments mis en avant)
  - Gris anthracite `#1F2A44` — texte courant
  - Blanc cassé `#FAFAFA` — fond
- Typographie sans-serif : Inter via Google Fonts CDN
- Design aéré, professionnel, style Stripe/Linear
- Mobile-friendly par défaut

## Règles de contenu

- Français uniquement
- Ton professionnel, pas commercial
- Pas de superlatifs (« révolutionnaire », « game-changer »)
- Les témoignages sont fictifs mais réalistes
